GitHub Configuration

Connect your admin dashboard directly to your website repository.

Security Guarantee: Your GitHub token never leaves your browser. It is saved strictly in your local browser storage (localStorage) and used solely for direct calls to api.github.com.

How to Get a Token

  1. Visit github.com/settings/tokens/new
  2. Set Note: Canvas Era Admin V2
  3. Expiration: Select 90 days or No Expiration
  4. Check scope: repo (Full control of private/public repositories)
  5. Click Generate token at bottom
  6. Copy the ghp_... string and paste it into Settings

System Architecture

Understanding how Canvas Era V2 manages your CMS directly without backends.

1. Direct Commit

When you click "Publish", the dashboard converts your cover image to Base64 and commits it directly to your GitHub repository under /images.

2. Automatic Indexing

The CMS reads your existing posts.js file, prepends the newly created artwork metadata, and commits the updated array back automatically.

3. Instant Deployment

Hosting services like Vercel, Netlify, or GitHub Pages detect the commit on branch main and trigger an automatic rebuild within seconds.

Expected File Structure on GitHub

For optimal syncing, your repository (canvasera.art) should maintain this structure:

canvasera.art/
├── index.html
├── posts.js           <-- Contains window.POSTS = [...]
└── images/            <-- Contains uploaded artwork image files
    ├── celestial-harmony.jpg
    └── futuristic-arch.webp
