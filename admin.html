Repository Setup

Local Security Architecture

Your GitHub token never leaves your browser. It is stored securely in localStorage on this device only. All API calls are made directly from your client to api.github.com.

Token Generation Guide

  1. Go to GitHub Developer Settings ↗
  2. Set Note: Canvas Era Admin V2
  3. Set Expiration: 90 days (Recommended)
  4. Select Scope: Check the repo box (Full control)
  5. Click Generate and paste the ghp_... token here.

How it works

Understanding the V2 CMS Architecture.

1

Direct GitHub Integration

This dashboard acts as a static CMS. When you publish a post, the browser uses the GitHub REST API to directly commit the optimized image to your repository's image folder.

2

Data Management

Along with the image, a metadata update is pushed to a JSON/JS file in your repo. This file acts as the database for Canvas Era, allowing the front-end to instantly read new posts without a traditional backend database.

3

Build Triggers

If your site is hosted on Vercel, Netlify, or GitHub Pages, the new commit will automatically trigger a re-deploy, updating your live site within seconds.
